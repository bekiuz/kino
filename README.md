# SKILLMATCH

**Bekiuz Team · HRTech · Uzbekistan**

SKILLMATCH — nomzodlarning ko‘nikmalarini amaliy ishlar va portfolio orqali namoyish etish, ish beruvchilarga esa mos nomzodlarni topishga yordam berish g‘oyasidagi HRTech platforma.

## MVP prototipi
Ushbu repozitoriy g‘oya bosqichidagi vizual va interaktiv frontend prototipini o‘z ichiga oladi.

### Ishlaydigan qismlar
- Responsive landing page.
- Nomzod va ish beruvchi uchun demo ro‘yxatdan o‘tish oynasi.
- Demo profillarni brauzer localStorage xotirasida saqlash.
- O‘zbek tilidagi platforma taqdimoti.

### Hozircha ulanmagan
- Haqiqiy autentifikatsiya va server bazasi.
- AI orqali baholash.
- Haqiqiy vakansiyalar va ishga joylashtirish.
- Shaxs yoki ko‘nikmalarni mustaqil tasdiqlash.

## Ishga tushirish
index.html faylini brauzerda oching yoki GitHub Pages orqali joylashtiring. Tashqi kutubxona yoki build vositasi talab qilinmaydi.

## Keyingi bosqich
1. Nomzod va kompaniya hisoblari uchun backend.
2. Kasblar va ko‘nikmalar katalogi.
3. Amaliy topshiriqlar va baholash mezonlari.
4. Portfolio va Skill Profile.
5. Ish beruvchilar uchun nomzod qidiruvi.
